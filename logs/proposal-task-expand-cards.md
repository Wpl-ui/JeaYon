# 方案：待办左右展开卡片 / Task horizontal expand cards

状态 / Status: **待确认 / awaiting approval**（只方案，未改代码）

## 你要的效果 / Requested

1. 展开方向改为**左右**（水平展开），不是现在的上下收高度。
2. **父任务、子任务都是独立组件**（卡片/块），不是扁平列表一行字。
3. 每个父、每个子可有**清新缤纷**的底色/强调色，彼此可不同（稳定随机，不是每次刷新狂跳）。
4. 子任务展开动画：**从短变长**，并且**依次**展开（错落，不是整组同时）。

## 现状 / Current

- 扁平 `ul > li`；折叠用竖直 `grid-template-rows: 1fr↔0fr`。
- 胶囊折叠 + sessionStorage + 同父拖拽已上线；无卡片色、无水平展开、无错落。

## 推荐交互 / Recommended UX

### 布局

- **父任务**：一张横向卡片（圆角、浅色底、左侧细色条）。
- **子任务区**：在父卡片**下方**仍占文档流（保证可滚动、可拖拽），但每张子卡做**水平「从短到长」**出现：
  - 收起：宽度≈0（或很窄色条）、opacity 0、不可聚焦（`inert`）。
  - 展开：宽度→100%（短→长），可加轻微 `scaleX` 或 `clip-path: inset(0 100% 0 0) → inset(0 0 0 0)`，时长约 220–280ms，ease Apple 曲线。
- 胶囊仍在父卡上控制展开；默认展开；sessionStorage 逻辑保留。

> 说明：「左右展开」落实为子卡**水平生长**；父卡位置不动。若你本意是子任务从父卡**右侧滑出成侧栏**，那是另一套布局（列表变主从分栏），本方案默认不做，可作为备选。

### 依次展开

- 展开时第 i 个子卡 `transition-delay: i * 40–60ms`（上限约 8 项，超出共用最大 delay，避免超长等待）。
- 收起时反向（先末后先）或统一快速收起（建议**统一快收**，展开才错落，更跟手）。
- `prefers-reduced-motion: reduce`：无 delay、瞬时到位。

### 颜色

- 预置 **8–12 个清新色**（低饱和 pastel：薄荷、天空、柠檬、桃粉、葡萄、杏橙等），深色模式用同色相更低亮度变体。
- **稳定映射**：`colorIndex = hash(task.id) % palette.length`（或 teamId+id），同一任务颜色固定；父子可不同。
- 用法：卡片背景 8–12% 透明填充 + 左侧 3–4px 实色条；文字仍用 `--ink`，保证对比度。
- **不要**每次挂载 `Math.random()`（会闪色）；不要高饱和霓虹（伤眼、不 Apple）。

### 组件拆分

- `ParentTaskCard`：标题、进度/状态、胶囊、操作、拖拽无关。
- `ChildTaskCard`：勾选、标题、拖拽手柄、短→长动画 class、色条。
- `TaskList` / `TasksPage`：只组数据、折叠、排序。
- 拖拽/键盘调序、乐观回滚契约不变；事件仍挂在可识别的 `data-task-id` 节点上。
